AKS deployment walkthrough

MedEmbed on AKS

How we self-host medical text embeddings on Azure Kubernetes Service with Hugging Face TEI, ClusterIP, and Istio.

abhinand/MedEmbed-base-v0.1 TEI cpu-1.9 CPU · ClusterIP Istio /medembed/

01 · Scope

What we deployed

A medical-domain embedding service for clinical and biomedical text — similarity, retrieval, and OpenAI-style clients.

PieceChoice
Modelabhinand/MedEmbed-base-v0.1
RuntimeHugging Face Text Embeddings Inference (TEI)
Imageghcr.io/huggingface/text-embeddings-inference:cpu-1.9
ComputeCPU only — no GPU node pool
PlatformAKS
ExposureClusterIP + optional Istio VirtualService

02 · Design choices

Why this shape

  • Self-hosted — clinical text stays inside the cluster
  • TEI — production embedding server with native and OpenAI-compatible APIs
  • CPU first — no GPU pool required for this model footprint
  • Shared recipe — same packaging as bge-small and vexyl-stt

Manifests we ship

medembed/

├── deployment.yaml            # TEI + probes + resources

Apply Namespace → Deployment → Service. Paste the Istio route into the existing VirtualService — do not apply the snippet alone.

06 · Rollout

Deploy steps

kubectl apply \
  -f medembed/namespace.yaml \
  -f medembed/deployment.yaml \
  -f medembed/service.yaml

kubectl -n medembed rollout status deploy/medembed
  • First boot downloads weights from Hugging Face — can take several minutes
  • ONNX 404 warnings on CPU are expected; TEI falls back to Candle + safetensors
  • Needs cluster egress to huggingface.co on cold start

07 · Mesh exposure

Istio VirtualService route

- match:
    - uri:
        prefix: /medembed/
  rewrite:
    uri: /
  route:
    - destination:
        host: medembed.medembed.svc.cluster.local
        port:
          number: 80

Gateway clients keep the /medembed/ prefix; Istio rewrites to TEI’s native paths.

  curl -s http://medembed.medembed.svc.cluster.local/embed \
  -H 'Content-Type: application/json' \

10 · Operations

Prerequisites & caveats

Need

  • kubectl for the AKS cluster
  • Node capacity: 2–4 CPU, 4–8Gi
  • Egress to Hugging Face on first start

Watch

  • emptyDir cache is lost on pod recreate
  • Pending / CrashLoop → egress or capacity
  • PVC or baked image if cold starts hurt

12 · Summary

Takeaways

  • MedEmbed runs as TEI on AKS CPU — no GPU required for this footprint
  • ClusterIP + Istio keeps exposure behind the existing mesh gateway
  • Probes tolerate cold start while Hugging Face weights download
  • Same layout as sibling ML services — easy to operate and extend
